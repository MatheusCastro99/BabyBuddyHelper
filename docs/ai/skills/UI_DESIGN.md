# UI_DESIGN

## Purpose

Guide the creation and evolution of BabyBuddyHelper's visual identity and user experience.

This skill exists to ensure all design decisions contribute toward a cohesive and recognizable Parenting Companion experience.

The goal is not simply to create an attractive interface.

The goal is to create an interface that feels:

- Warm
- Calm
- Supportive
- Encouraging

while remaining practical, accessible, and easy to use.

---

## When To Use

Use this skill when:

- Designing new screens.
- Planning UI redesigns.
- Creating visual components.
- Defining design systems.
- Selecting colors and styles.
- Designing navigation flows.
- Evaluating visual direction.

Do NOT use when:

- Reviewing implementation quality.
- Reviewing architecture.
- Evaluating technical debt.
- Planning features.

Use:

- FEATURE_PLAN for feature evaluation.
- CODE_REVIEW for implementation review.
- ARCHITECTURE_REVIEW for architectural decisions.
- TECH_DEBT_ANALYSE for technical debt evaluation.

---

## Design Philosophy

BabyBuddyHelper is a:

Parenting Companion

NOT a:

- Corporate Productivity Tool
- Enterprise Dashboard
- Clinical Healthcare Application
- Generic Task Manager

Every interface decision should reinforce the Parenting Companion identity.

---

## Desired Emotional Response

The application should feel:

### Warm

Users should feel welcomed and supported.

Examples:

- Friendly language
- Rounded shapes
- Soft color palette

---

### Calm

Users should not feel overwhelmed.

Examples:

- Minimal clutter
- Comfortable spacing
- Clear organization

---

### Encouraging

The application should celebrate progress.

Examples:

- Positive completion feedback
- Friendly messaging
- Gentle reminders

---

### Supportive

The application should reduce stress.

Examples:

- Clear action paths
- Helpful information placement
- Predictable workflows

---

## Visual Design Principles

### Simple First

Favor:

- Clear layouts
- Minimal visual noise
- Obvious interactions

Avoid:

- Excessive effects
- Unnecessary animations
- Decorative complexity

---

### Comfortable Spacing

Favor:

- Generous whitespace
- Breathing room between elements
- Clear visual grouping

Avoid:

- Dense layouts
- Information overload

---

### Rounded Components

Favor:

- Cards
- Soft corners
- Friendly shapes

Examples:

- Appointment Cards
- Task Cards
- Summary Cards

---

### Friendly Typography

Favor:

- Readable fonts
- Comfortable sizing
- Clear hierarchy

Avoid:

- Tiny text
- Excessive font variety

---

## Color Guidance

Current Direction:

Soft, encouraging colors.

Desired Feel:

- Calm
- Trustworthy
- Family-friendly

Potential Palette Characteristics:

- Soft Blues
- Soft Greens
- Warm Creams
- Gentle Accent Colors

Avoid:

- Harsh reds
- Aggressive contrast
- Corporate grayscale themes

---

## Navigation Principles

Navigation should be:

- Predictable
- Simple
- Easy to learn

Users should always know:

- Where they are
- What they can do next
- How to return

Favor:

- Clear navigation paths
- Consistent placement

Avoid:

- Hidden actions
- Deep navigation chains

---

## Screen Design Priorities

### Dashboard

Purpose:

Provide reassurance and situational awareness.

Should answer:

"What does my day look like?"

---

### Checklist

Purpose:

Support task completion with minimal friction.

Should answer:

"What needs my attention?"

---

### Calendar

Purpose:

Provide visual schedule awareness.

Should answer:

"When is everything happening?"

---

### Add/Edit Experience

Purpose:

Enable fast and stress-free data entry.

Should answer:

"What information do I need right now?"

---

## Companion Alignment

Future companion features should feel:

- Helpful
- Gentle
- Friendly

NOT:

- Distracting
- Noisy
- Attention-seeking

The companion should support the user experience rather than dominate it.

---

## Design System Guidance

Favor reusable:

- Colors
- Typography
- Styles
- Templates
- Components

Goal:

Visual consistency across all pages.

Future implementation should centralize visual definitions whenever practical.

---

## Evaluation Questions

When reviewing a design, ask:

1. Does this feel like a Parenting Companion?
2. Does it reduce stress?
3. Is it approachable?
4. Is it visually calm?
5. Does it maintain clarity?
6. Is the design consistent?
